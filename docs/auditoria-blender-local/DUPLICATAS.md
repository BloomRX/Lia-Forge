# Comparação com as 19 famílias da pesquisa anterior

A [pesquisa revisada](../ECOSYSTEM-RESEARCH-BLENDER-ADDONS.md) usa 19 famílias de add-ons e assets, incluindo seis vistos em duas fontes anteriores. SHA-256 repetido nesta auditoria prova equivalência dos bytes comparados. A correspondência histórica é por identidade, versão e tipo, pois o estudo anterior não fornece um checksum comparável para todos os itens.

| Família anterior | Resultado local |
| --- | --- |
| SquishyFX | 3.3.0 e 3.40.0, versões distintas. |
| JiggleGen | 2.0.0, manifesto GPL-3.0-or-later e uma cópia em pacote aninhado. |
| JiggleMaker | 2.0.0 e 2.2.2, versões distintas. |
| HairCard Studio | Embalagens 1.0, 1.1 e 1.5 com metadados internos 1.0. |
| Braids Generator | CTools Braids 5.1.1 e material de exemplo. |
| Genshin Impact Character Shader | Cena direta e pacote rotulado 2.2.2. Direitos de material e arte pendentes. |
| Bodiez | Bases modulares e pacote de origem provável. As revisões devem ser relacionadas por hash e evidência de proveniência. |
| Voxel Heat Diffuse Skinning | 3.5.3, com executáveis auxiliares. |
| Cloth NeXt | 2.4.0, pacote Windows com executável. |
| Dovetail Key | 5.0.1. Mínimo 4.2 no manifesto e 3.0 no bl_info. |
| Projection Modeling | 1.1.4, autoria dependente de contexto. |

| Goo Physics | 1.0.0, com exemplo de cena. |
| Wiggle Bones | 1.1.2. O Wiggle Bone de um tutorial usa outro namespace. |
| SUPERTABs | 1.3.0, organização de interface. |
| Car_Rig | Pacote homônimo sem identificação confirmada. |
| SquishBulge GeoNodes | Cena de deformação, com duas árvores Geometry Nodes e quatro Actions serializadas. |
| Motion2MixamoRig | Sem identificação confirmada. Os outros retargeters têm identidade própria. |
| SKkeeper | 1.8.2, ID shapekey_keeper. |

RetopoFlow, MPFB, MMD Tools e VRM Add-on passam de referências comunitárias a exemplares locais identificados. MPFB 2.0.15 declara GPL para código, corrigindo a atribuição de AGPL ao MPFB na pesquisa anterior. A comunidade reserva AGPL para o código MakeHuman e CC0 para recursos core. RetopoFlow 4.0.2 tem evidência local de licença e compatibilidade que precisa ser registrada por versão. [Licenças e dependências](LICENCAS-E-DEPENDENCIAS.md)

Entre as descobertas adicionais estão Animation Snapper e Switcher, Auto-Rig Pro e auxiliares, Seamless CAD, Auto Unwrap, PaletteGrid, Sanctus, SpringFX, TrueSKY, Onion Skinning, ferramentas de ajuste de roupa, autoria de hair e o painel Bloom Agent.
